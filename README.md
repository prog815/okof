# 📦 Интерактивный справочник ОКОФ

Онлайн-справочник по Общероссийскому классификатору основных фондов (ОК 013-2014 (СНС 2008)). Справочник создан на основе официального машиночитаемого снимка.

🌐 Сайт: [https://prog815.github.io/okof/](https://prog815.github.io/okof/)

Этот справочник — для тех, кто подбирает коды основных средств для бухгалтерского и налогового учёта, инвентарных карточек, первичных документов и учётных систем. Главная задача — помочь быстро найти корректный код ОКОФ по названию объекта или по самому коду (с точками и без) и скопировать его в один клик.

---

## Что кодирует ОКОФ

**ОКОФ** — общероссийский классификатор, в котором записаны **объекты основных фондов** (здания, сооружения, машины, оборудование, транспорт, программное обеспечение), а не продукция, не виды деятельности и не амортизационные группы. Он отвечает на вопрос **«что это за основное средство»**.

В текущем снимке справочника содержится **2134 записи**. Классификатор разбит на 22 вида основных фондов (определяются первыми тремя цифрами кода).

Каждая карточка содержит:
- **Код с точками** (например, `100.00.00.00`). Используется в официальных документах.
- **Код без точек** (например, `100000000`). Используется в учётных системах (1С, Excel), где точки мешают сортировке.
- **Наименование** (например, «Жилые здания и помещения»).
- **Раздел** (например, «§100 Жилые здания и помещения»).

## Для кого и зачем

Справочник предназначен для бухгалтеров, специалистов по учёту имущества, разработчиков учётных систем (1С, SAP, ERP) и сотрудников, отвечающих за подготовку первичных документов.

Он пригодится, если вам нужно:
- поставить объект на бухгалтерский и налоговый учёт и подобрать правильный код ОКОФ;
- заполнить инвентарную карточку, акт приёма-передачи, первичные документы;
- подставить код в учётную систему, где формат кода критичен (с точками или без);
- расшифровать код из чужого документа и понять, что за объект за ним стоит;
- подготовить данные для поиска объекта в Постановлении Правительства РФ № 1 (амортизационные группы).

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти» и без перезагрузки.
- **Поиск по коду.** Введите `100.00.00.00`, `100000000` или `100`, чтобы мгновенно найти нужную форму. Поиск строго с начала кода.
- **Поиск по названию.** Одно или несколько слов по логике «И»: `жилые здания` или `станки лазерные`.
- **Два формата кода в карточке.** Код с точками и код без точек. Оба копируются одним кликом. Оба ведут на прямую ссылку `?code=`.
- **Фильтры по разделам.** Выпадающий список 22 видов ОФ.
- **Плоский список.** Все записи выстроены единым списком. В официальном источнике есть иерархия, однако для удобства поиска справочник представлен плоским списком, сгруппированным по 22 видам ОФ.
- **Копирование в один клик.** Клик по коду копирует его в буфер обмена. Внизу экрана появится подтверждение.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере. В текст автоматически подставляются код, наименование и раздел.
- **Прямые ссылки на коды.** Каждый код можно передать коллеге через `?code=…` в адресе.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке.

## Как пользоваться

1. **Откройте страницу** — сразу показывается первая порция записей.
2. **Начните вводить запрос** — код (с точками или без) или слово из названия.
3. **Используйте фильтр**, если нужно сузить поиск до конкретного вида ОФ.
4. **Кликните по коду с точками или без точек** в карточке — он скопируется.
5. **Нажмите `📤 Поделиться`**, чтобы отправить карточку коллеге.
6. **Прокручивайте вниз** и нажимайте «Показать ещё» — результаты догружаются порциями по 20.

> **Важно про формат кода.** В официальных документах код ОКОФ пишется с точками: `100.00.00.00`, `210.00.11.10.110`. В учётных системах, Excel и некоторых базах данных точки убирают, чтобы код корректно сортировался: `100000000`, `210001110110`. В карточке справочника показаны оба варианта — копируйте тот, который требует ваша система. Длина кода при этом бывает разной: от 5 до 12 цифр.

## Примеры запросов

- `100.00.00.00` или `100000000` — Жилые здания и помещения.
- `жилые здания` — все объекты с этим словосочетанием.
- `320.26` — Компьютеры и периферийное оборудование.
- `ноутбук` — Ноутбуки и портативные компьютеры.
- `330.28.41.11.100` — Станки лазерные.
- `730.00` — Программное обеспечение и базы данных.

**Популярные коды:**
- `100.00.00.00` / `100000000` — Жилые здания и помещения;
- `210.00.00.00.000` / `210000000000` — Здания (кроме жилых);
- `220.00.00.00.000` / `220000000000` — Сооружения;
- `310.29.10.2` / `31029102` — Автомобили легковые;
- `320.26.20.11.110` / `320262011110` — Ноутбуки;
- `330.28.41.11.100` / `330284111100` — Станки лазерные;
- `730.00.00.00` / `730000000` — Программное обеспечение и базы данных.

## Прямые ссылки на коды

Каждый код можно открыть напрямую — например:
- `https://prog815.github.io/okof/?code=100000000` — откроет карточку «Жилые здания и помещения».
- `https://prog815.github.io/okof/?code=320262011110` — откроет карточку «Ноутбуки».
- `https://prog815.github.io/okof/?code=330.28.41.11.100` — тот же код с точками, тоже откроется.

Ссылка с `?code=` сразу подставляет код в строку поиска и подсвечивает нужную карточку. Пока идёт deep-link, поиск работает по точному совпадению кода — `?code=100000000` не вывалит весь раздел `100`.
